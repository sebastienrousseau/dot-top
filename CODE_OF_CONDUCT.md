# Code of Conduct

This project adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Everyone who takes part in its issues, pull requests and discussions is
expected to follow it.

Report unacceptable behaviour privately to the maintainer,
[@sebastienrousseau](https://github.com/sebastienrousseau) on GitHub.
Reports are handled in confidence.
